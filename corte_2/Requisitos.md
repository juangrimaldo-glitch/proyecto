## Requsitos funcionales:
* LOGIN:El sistema debe permitir a los usuarios iniciar sesión mediante credenciales (usuario y contraseña), validando su acceso y permitiendo el uso del sistema según su rol.
* GESTION DE PRODUCTOS: Debe permitir registrar el nombre del producto la cantidad en stock, precio, codigo.
* PROCESO DE VENTAS: Debe permitir registrar ventas diarias, ingresar datos de la venta(producto,cantidad), validar si hay stock disponible y descontar automaticamente la cantidad.
* INVENTARIO: Debe permitir actualizar el inventario despues de la venta, mostrar la tabla de productos actualizados y controlar la cantidad disponible de cada producto.
* ALERTAS: Debe notificar al administrador cuando se esta agotando la cantidad de productos y  cuando no hay stock.
* REPORTE: El sistema debe mostar al administrador las estadisticas mensuales y los reportes de cada mes.
* BUSQUEDA DE PRODUCTOS: El sistema debe permitir buscar productos por nombre o código.
* MODIFICACION DE PRODUCTOS: El sistema debe editar la información de los productos registrados.
* ELIMINACION DE PRODUCTOS: El sistema debe permitir eliminar productos del inventario.
* GESTION DE DEVOLUCIONES: El sistema debe permitir el reingreso automático al inventario de productos devueltos que están en buen estado.

## Requisitos no funcionales:
*   RENDIMIENTO: El sistema debe actualizar el inventario en tiempo real y las consultas deben responder rapidamente, debe permitir registrar productos sin afectar el uso del sistema al mismo tiempo
*   SEGURIDAD: El sistema debe permitir el acceso a los usuarios registrados previamente y proteger los datos de almacenanmiento.
*   FIABILIDAD: El sistema debe permitir guardar los datos sin ninguna perdida y evitar errores en el calculo de stock.
*   DISPONIBILIDAD: El sistema debe estar disponible en el horario de ventas sin fallas.
*   USABILIDAD: El sistema debe ser fácil de usar, con una interfaz clara y comprensible para el usuario.
*   MANTENIBILIDAD: El sistema debe permitir realizar cambios o actualizaciones de manera sencilla sin afectar su funcionamiento.
*   COMPATIBILIDAD: El sistema debe poder ejecutarse en diferentes sistemas operativos o dispositivos sin problemas.
*   PORTABILIDAD: El sistema debe poder instalarse y ejecutarse en diferentes entornos sin requerir grandes modificaciones.
