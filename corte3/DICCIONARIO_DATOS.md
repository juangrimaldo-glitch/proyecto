1) ¿Qué ROL es el encargado de capturar estos datos?
El Administrador de la tienda que usa nuestro sistema de Tienda SC, es el encargado de registrar y actualizar los productos del inventario, ademas de ver los reportes que genera nuestro sistema para la toma de decisiones.

3) ¿Qué FUNCIÓN de validación debe realizar el sistema automáticamente?
El sistema debe validar lo siguiente:
No se deben registrar productos con datos vacíos o incorrectos.
La cantidad de productos ingresada sea numérica y mayor a cero.
No se puedan vender productos sin stock disponible.
Las ventas queden registradas correctamente con fecha, cantidad y producto vendido.
Los usuarios ingresen según su rol (Administrador o Trabajador) y solo accedan a las funciones permitidas.

5) ¿Qué sucede con la información del sistema si este Rol no cumple su Función?
El inventario puede mostrar cantidades incorrectas.
Los reportes y estadísticas serían erróneos.
Puede haber descontrol en el stock, causando faltantes o exceso de productos.
El trabajador ya no podria vender productos ya que al momento de agotarse no se ingresarian mas productos.
